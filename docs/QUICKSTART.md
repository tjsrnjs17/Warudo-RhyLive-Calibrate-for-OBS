# Quick start

Close OBS, copy the DLL into your OBS installation's `obs-plugins/64bit` folder, and restart OBS. Run Warudo on the same PC with exactly one active RhyLive Receiver. Face forward and keep your head still when pressing the button below Settings.

| Language | Button | Installation and use |
| --- | --- | --- |
| English | Recalibrate | Copy the DLL into `obs-plugins/64bit`, restart OBS, and click Recalibrate below Settings. |
| 한국어 | 캘리 | DLL을 `obs-plugins/64bit`에 넣고 OBS를 재시작한 뒤 설정 아래의 캘리를 누릅니다. |
| 日本語 | 再調整 | DLLを `obs-plugins/64bit` にコピーし、OBSを再起動して設定の下にある再調整をクリックします。 |
| 简体中文 | 重新校准 | 将 DLL 放入 `obs-plugins/64bit`，重启 OBS，然后点击设置下方的重新校准。 |
| 繁體中文 | 重新校正 | 將 DLL 放入 `obs-plugins/64bit`，重新啟動 OBS，然後點擊設定下方的重新校正。 |
| Deutsch | Neu kalibrieren | DLL nach `obs-plugins/64bit` kopieren, OBS neu starten und unter Einstellungen auf Neu kalibrieren klicken. |
| Français | Recalibrer | Copiez la DLL dans `obs-plugins/64bit`, redémarrez OBS et cliquez sur Recalibrer sous Paramètres. |
| Español | Recalibrar | Copie la DLL en `obs-plugins/64bit`, reinicie OBS y haga clic en Recalibrar debajo de Ajustes. |
| Português | Recalibrar | Copie a DLL para `obs-plugins/64bit`, reinicie o OBS e clique em Recalibrar abaixo de Configurações. |

The UI follows the OBS language. Unsupported languages use English. Translations are embedded in the DLL; locale JSON files are for source builds only.
